# Ethos

Open `app/Ethos.xcodeproj` in Xcode. Open this repository root in VS Code.

- `app/Sources/App/`: application entry point.
- `app/Sources/Features/Home/`: starter screen.
- `app/Sources/Resources/`: asset catalogs.
- `planning/`: project planning documents.

Xcode synchronizes the Sources folder automatically. Add Domain and Data folders when implementing habit rules and persistence.

The original nested Xcode Git repository is preserved in `.git/xcode-project-history-backup`; the root repository now tracks the app.
